One-time setup (kept in this browser only)
Why log in each morning? Kite's own 5-minute NIFTY candles replace Yahoo's, which freeze before the close. Kite's access token lasts one day (until 06:00), so log in once before 09:15. Without a login, the app uses Yahoo as before. The app only reads prices; it never places orders.

  2. Each morning: tap Log in to Kite, log in, and wait here for "Logged in".
