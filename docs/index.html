Connect the buttons to GitHub

These buttons start the same jobs that run on a schedule (GitHub Actions in this site's repository). To start them from this page, it needs a GitHub token that is allowed to run them. The token is kept only in this browser and is sent only to GitHub.

  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories → this repository.
  3. Permissions → Repository → Actions: Read and write. Nothing else is needed. Pick an expiry date.
  4. Generate, copy and paste it here.
